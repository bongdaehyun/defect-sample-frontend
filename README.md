# defect-sample-frontend

결함 처리 흐름 자동화 프로젝트에서 쓰는 샘플 게시판의 프론트엔드입니다. 백엔드는 [defect-sample-backend](https://github.com/bongdaehyun/defect-sample-backend)에 있습니다.

- React, TypeScript, Vite
- 실행: 백엔드를 띄운 뒤 `npm install && npm run dev`. `/api` 요청은 `localhost:8080`으로 넘깁니다.
- 화면 오른쪽 위에서 고른 사용자를 `X-User-Id` 헤더로 보냅니다. 로그인은 없습니다.
